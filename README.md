# Prompt Engineering - Day 1 Assignment

## Overview

This repository contains my Day 1 Prompt Engineering assignment demonstrating four fundamental prompting techniques used with Large Language Models (LLMs).

The objective is to understand how prompt design influences the quality, clarity, and accuracy of AI-generated responses.

---

## Prompting Techniques Covered

- Zero-Shot Prompting
- Few-Shot Prompting
- Chain-of-Thought Prompting
- Role Prompting

Each technique includes:
- Before Prompt
- Before Output
- Improved Prompt
- After Output
- Explanation of Improvement
